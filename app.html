Appearance

Your accounts

Public usernames only. The browser asks the site directly; nothing is signed in to.

Reading

Move phrases are a closed vocabulary and are read freely. Unique text — a finding, a card, a briefing — is a Speak button, and by default those buttons live only in Listen.

Memory

Engine

Stockfish runs in this browser by default; the 7 MB is fetched the first time you press Analyse. Point a remote engine here and the long jobs can run elsewhere — see docs/engine.md for the two transports and the reference server.

AI provider

One block serving both the voice and the “Why?” explanations. Any OpenAI-compatible server works: OpenAI itself, a local LM Studio or Ollama, OpenRouter, your own proxy. The browser calls it directly, so the endpoint has to allow that (CORS) — the README has a four-line proxy for the ones that do not.

The key is stored in this browser’s localStorage, in plain text, and is sent only to the base URL above.

Sync (optional)

Off by default; the app is complete without it. A self-hosted server that stores five blobs — see docs/sync.md for the contract and the reference server.

About

ChessReader is free software under the GNU GPL v3. Everything is computed in this browser; nothing leaves it unless you configure an endpoint above.

Engine: Stockfish 17.1 (GPL v3). Rules: chess.js. Pieces: the Cburnett set by Colin M.L. Burnett, CC BY-SA 3.0. Opening names: the Lichess chess-openings database.
